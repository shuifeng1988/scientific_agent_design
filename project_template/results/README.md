## 📋 Required task report

Every task README includes project/plan links, data descriptions and sources, software versions and use, exact commands, cohort and methods, QC, tables, figures, results, conclusions, limitations, reflection, and next action. Technical logs and hashes stay in `_evidence/`.

Interpret each substantive result with a real literature search (query/date/source/support or conflict), preregistered expected-versus-observed comparison, uncertainty and alternative explanations. State whether the original expectation was appropriate and how the observation affects each dependent task's premise and expected information value. Save run-bound qc.json and reflection.json per continuous_execution.md; the scheduler releases dependent tasks only after these checks.
